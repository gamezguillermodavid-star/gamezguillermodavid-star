# Hola, soy Guillermo

Desarrollador full-stack en Barcelona y fundador de DigiCore Live.

Pasé de ser encargado de bares en grandes evento (Anella Olimpica de Montjuic, RCDE, FCB, Zoo y Circuit de Catalunya) a crear el software que habría querido tener entonces. Soy Guillermo Gámez, desarrollador full stack y autónomo, y mi recorrido no se parece al de la mayoría de desarrolladores. 
Esa experiencia me dio algo que no se aprende solo programando: sé cómo trabaja la gente de verdad, con prisa, con presión y con herramientas que no siempre ayudan. Por eso creo software pensado para quien lo usa.


## Lo que hago
- Analizar el problema, diseñar la solución, programarla, publicarla y mantenerla.
- Aplicaciones web a medida para empresas y eventos.
- Control de personal y fichaje en tiempo real.

## Mis proyectos
- **DigiCore Live**: plataforma para coordinar personal, fichaje y supervisión en eventos. Probada con 55.000 espectadores y 37 puestos a la vez. https://digicorelive.com
- **Convitia**: web para organizar eventos y repartir invitados en mesas.
- **Surtify**: app de precios de gasolineras.
